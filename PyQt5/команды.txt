Правой кнопкой мыши по папке ui файл -> Open In ->  Terminal  для того чтобы открыть терминал в нужной папке
pyuic5 -x "название.ui" -o "название.py" - команда для преобразования ui в py

Правой кнопкой мыши по папке qrc файлы -> Open In ->  Terminal  для того чтобы открыть терминал в нужной папке
pyrcc5 "название.qrc" -o "название_rc.py"
